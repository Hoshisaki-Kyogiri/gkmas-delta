# 官网视觉参考与工具界面转译

2026-10-13 直接查看了 [官网首页](https://gakuen.idolmaster-official.jp/) 与 [学园案内 / Media](https://gakuen.idolmaster-official.jp/media/) 的浏览器渲染。以下是对呈现方式的观察和本原型的设计判断，不代表官方公开的设计规范。

## 观察到的视觉特征

- 白色内容底面，彩色细线框与轻字重文字。
- 按钮、内容入口、媒体缩略图反复使用对角圆角。
- 媒体缩略图采用外侧线框与内侧圆角图片的组合。
- 导航、分类和点击入口具有一致的形状语言。
- 官网使用橙色、粉色与其他彩色元素，背景存在低对比几何纹样；页面字体实际声明为 IBM Plex Sans JP。

## 本原型采用的处理

| 官网呈现 | 工具中的对应做法 |
| --- | --- |
| 白底与彩色细框 | 主内容改为白底，紫色细框划分更新任务和资源入口 |
| 对角圆角 | 导航选中项、分类按钮、主操作与缩略图内框采用一致的对角圆角 |
| 轻字重与间距 | 沿用已分发的 Noto Sans SC / Quicksand，控制标题字重与字距 |
| 媒体外框与内图 | 184px 上限的缩略图加细框，内部图片按原比例居中留白；根据批注取消图片本体的圆角裁切 |
| 清楚的栏目入口 | 六个功能入口保留，并加入各自的细线图标 |

保留项目紫色 `#706CAA`、猪图标、紧凑缩略图与信息系统结构。数字、文件元数据、任务状态与按钮仍按操作优先级组织。没有引入新的宣传标题、宣传副标题、首屏视频、官网校徽或大幅人物立绘。

`gakuen.css` 是本原型独立编写的样式；未复制官网 CSS 或脚本。唯一取自官方的图片是概览统计区的底纹 `gkmas_delta/web/assets/band-pattern.webp`：由官方发布的制服几何纹样素材缩放并做紫色双色调处理而成，版权归原权利人所有。官网展示中的超轻字重未照搬到工具正文，以保持数据可读性。

右上角的“学园”样式为本次默认方向。Swiss 与 Editorial 留作比较；它们不是本次官网参考的结果。
