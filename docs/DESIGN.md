# 紫色配色与文案调整

当前默认为“学园”方案，官网视觉参考与对应的工具设计处理见 [OFFICIAL_REFERENCE.md](OFFICIAL_REFERENCE.md)。本文中的 Swiss / Editorial 配色保留作为早期方案记录。

## 信息系统设计原则

将网站视为信息系统。先确定信息架构、操作路径和需要展示的数据，再安排网格、字体与颜色。

- 标题直接表示页面、对象或任务，不写无实际信息量的宣传句。
- 副标题仅在解释范围、单位、限制或操作后果时保留；标题和页面已有信息不再重复。
- 优先级为任务状态和主要操作、数据判断、资源定位、次要元数据。
- 概览按版本/待更新量、更新任务/日志、资源入口、文件列表组织。大幅卡面放在图像浏览页。
- 列表展示可用于查找和判断的文件名、类别、角色、版本、大小，而不是装饰编号与重复翻译。
- 紫色用于操作、选择和状态。状态同时有文字，不只依赖颜色。
- Swiss / Editorial 共用信息架构与数字排版；衬线主要用于阅读正文。

此原则落实于当前的六页界面，更新、转换、配置保存等操作直接调用本项目后端的接口。

### 图标、字体与缩略图修订

- 恢复原项目的猪图标，原图保持不变，并同时用作 favicon。
- logo 使用原项目的 Quicksand Variable，600 字重；界面使用 Noto Sans SC Variable，正文 400、标题 500，数字保持表格数字对齐。
- 删除概览底部的图片文件表。
- 图片与视频采用紧凑网格，桌面卡片最大 184px 宽；图片为 4:3 缩略图，视频为 16:9。大图仍在详情弹窗中查看。
- 字体从本地文件加载，许可证随文件保留。

### 预览图与日志可读性

- 日志正文为 13px Noto Sans SC，时间为 12px 等宽字体；取消整行使用 10px 等宽字体的处理。
- 所有资源预览采用 `object-fit: contain` 并居中，图片、视频封面、音频封面和列表缩略图保持原始比例，以框内留白容纳尺寸差异。
- 取消预览图的圆角裁切和鼠标悬停放大，外部线框与按钮样式继续保留。

参考原控制台的 `--accent: #706caa`，将首版原型的朱红 / 墨红主色换回原项目紫色。原控制台文件已移除，设计只保留当前一套界面。

## 细节精修（0.1.4）

规则集中在 `gkmas_delta/web/refine.css`，叠加在 `type.css` 之后，选择器统一以 `:root[data-style]` 开头以覆盖 `gakuen.css`。

- 页眉右上角加入当页英文描边大字（OVERVIEW / IMAGES / …），字体为 Delta Outline：由 Comfortaa 700 去除轮廓重叠、加宽 `r` 后改名，仅含拉丁字母。
- 概览的统计区改为实色紫底，叠加官方几何底纹的双色调处理图（`assets/band-pattern.webp`），白字对比度 ≥ 4.7:1。
- 对角圆角只留给导航、主按钮与大面板；徽标、表格按钮、输入框等改为 4px 小圆角。
- 标签页、阅读器工具、音频分段等控件改为纯文字加细竖线分隔；工具栏搜索框与下拉框只保留下划线。
- 下拉菜单在支持 `appearance: base-select` 的浏览器（Chrome 135+）中使用与界面一致的字体、边框与选中样式，其他浏览器保持系统样式。
- 剧情列表去掉左侧圆角竖条，选中项改为浅色底；标题 15px、说明 13px。
- 图片与视频卡片以文件名作为标题，不再显示角色名、「根目录」与重复的版本标签；视频页加入网格 / 列表切换，切换按钮去掉边框。
- 剧情正文的日文改用日文字体栈（Noto Sans/Serif JP、BIZ UD、Yu Gothic / Yu Mincho、Meiryo），避免中文字形。
- 概览移除「检查服务器版本」链接（启动与任务结束时已自动检查）；主按钮去掉内侧细线。

## 配色

| 用途 | Swiss | Editorial | 理由 |
| --- | --- | --- | --- |
| 主色、按钮、进度 | `#706CAA` | `#706CAA` | 保留项目原有识别色，两种排版风格共用 |
| 小字号紫色文字 | `#625E9C` | `#625E9C` | 在带色浅底上加深文字，避免原主色显淡 |
| 背景 | `#F5F4F8` | `#F6F3F5` | 冷白用于控制台，暖灰用于衬线阅读排版 |
| 面板 | `#FDFCFE` | `#FFFDFD` | 与背景形成轻微明度区分 |
| 正文 | `#292633` | `#302936` | 紫色倾向的深炭灰，保持文字对比 |
| 辅助文字 | `#6D677B` | `#746776` | 不通过降低整体透明度来弱化信息 |
| 分隔线 | `#D9D6E2` | `#DDD5DF` | 用偏紫灰线维持网格层级 |
| 选中底色 | `#E9E6F4` | `#E9E6F4` | 侧栏和筛选状态使用浅薰衣草色 |
| 下载组成次色 | `#AAA5C8`、`#CBC8D8` | 同左 | 同色系层次，避免多种高饱和颜色与卡面竞争 |
| 完成状态 | `#527462` | `#527462` | 低饱和绿与勾号共同表达完成，仅在状态需要时出现 |

原主色与白字的计算对比度约 4.76:1。原主色作为小字号文字，在这两种带色背景上的对比度约 4.3:1，因此小字号使用加深后的文字紫色。辅助灰字与各自背景的对比度约 4.95:1 / 4.83:1。

紫色只用于交互、选中与重要状态，资源图片保留原色。排版通过字号、留白、网格和线条建立层级。
