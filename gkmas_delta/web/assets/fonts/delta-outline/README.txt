Delta Outline is a modified version of Comfortaa (weight 700): Latin letters
only, overlapping contours merged so outline-only text draws one clean edge;
"r" is 0.06em wider so its arm does not touch the next letter at tight tracking.
"I" has rounded short crossbars; "a" and "g" retain their single-storey forms.
Non-descending letters sit on the baseline. Typographic ascent/descent are
1em/0 so the page heading can align the letters with its divider and clip
descenders below it. Reproduce with tools/refine_outline_font.py (fonttools[woff]).
Renamed because "Comfortaa" is a Reserved Font Name under the OFL (see LICENSE).
